# عصابة الملاعب

لعبة اجتماعية أونلاين: ينشئ كل لاعب فريقاً من عشرة لاعبين ويخفي زعيمين، ثم يتعاون اللاعبون ويتنافسون لكشف الزعماء واستبعاد أو اغتيال الأهداف.

## البنية

- `src/App.tsx`: واجهة اللعبة، إنشاء الغرف، الانضمام، تجهيز الفرق، والمزامنة.
- `app/api/[...path]/route.ts`: API الغرف والجلسات والروستر والكروت والأحداث.
- `app/api/cron/cleanup/route.ts`: تنظيف الغرف القديمة المجدول عبر Vercel Cron.
- `vercel.json`: إعداد build وCron للنشر.

## التشغيل

يتطلب الاتصال قاعدة PostgreSQL عبر متغيرات AWS/RDS الموجودة في بيئة Vercel. المسار الأساسي هو اللعب الأونلاين؛ يتوفر الوضع المحلي للتجربة فقط.

## الأمان

تستخدم طلبات اللاعب `Authorization: Bearer <sessionToken>`، ولا تُكشف هوية الزعيم للخصوم إلا عند حدث كشف مصادق عليه. حالة اللعبة محفوظة على الخادم وليست مصدر الحقيقة من العميل.
